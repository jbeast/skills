# skills

## Skills

### irrefutable-proof

Type `/irrefutable-proof` to ask your agent for irrefutable proof that the current change works.

### xd-to-code

Give your agent an Adobe XD share link (`xd.adobe.com/view/...`) and ask it to make a component match the design. It captures every artboard with headless Chromium, extracts exact specs, renders tall artboards whole, measures the real component in the same states, and closes the gaps. Needs Node, Python 3 and Playwright with Chromium.
